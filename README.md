# 法答网精选问答数据集

## 数据源简介

本仓库收录了来自**最高人民法院“法答网”**的精选问答内容。法答网是人民法院系统内部用于法律适用问题咨询、研讨和交流的专业平台，其发布的答疑意见代表了最高司法机关的权威解释，对法律实务工作者具有极高的参考价值。

**选择该数据源的理由：**

- **权威性强**：法答网由最高人民法院主导建设，答疑专家多为资深法官及审判业务专家，其解答在法律适用层面具有很强的指导意义。
- **实务导向**：内容紧密结合审判实践中的疑难复杂问题，覆盖刑事、民事、行政、执行等多个领域，对律师、法官、学者等法律从业者均有参考意义。
- **必须收录**：对于从事中国法律实务与研究的人来说，法答网的解答是当前最为权威的一手素材之一，是法律知识库建设中不可或缺的组成部分。

## 数据采集方法

本数据集通过 **OpenCLI** 工具，在**最高人民法院官方网站**进行自动化采集。

- **采集工具**：opencli
- **采集目标**：最高人民法院法答网公开发布的精选问答页面
- **采集方式**：使用 opencli 驱动浏览器，按照目标网站的页面结构，依次抓取问题与答疑内容，并导出为 Markdown 格式文件保存到本地。

OpenCLI 的使用使得整个采集过程可控、可复现，便于后续根据网站更新进行增量补充。

## 数据清洗与脱敏

原始抓取的 Markdown 文件包含网页中残留的导航、广告、脚本等多余信息，不利于直接阅读与分析。为此，我们使用 **Codex** 编写并运行了清洗脚本，对原始数据进行了结构化处理。

### 清洗内容

- 去除网页模板、HTML 标签、无关脚本及重复导航元素
- 统一标题层级与格式，保证问题与答疑之间的层级清晰
- 修正 Markdown 排版，提升阅读体验
- 删除空行、乱码及无意义符号

### 脱敏方法

为保护当事人隐私并避免不必要的关联，所有涉及具体个人姓名的内容（包括姓名及所任职务）均已使用“某某”进行替换。

- **替换规则**：人名 + 职务统一替换为“某某”，例如“张三法官”替换为“某某法官”
- **保留规则**：法律问题、案件事实、法律分析、裁判思路等核心内容完整保留，不影响阅读和理解
- **目的**：在保护隐私的同时，确保问答的专业价值与可读性不受影响
